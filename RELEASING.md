# Выпуск Branch Tree

Репозиторий: https://github.com/wermusmoose/skilltree_plugin
Основная ветка: main. ID установленного плагина: branch-tree.

1. Прочитать AGENTS.md, проверить git status и получить актуальную историю через git fetch origin.
2. Обновить исходники и согласованную версию в manifest.json, package.json, package-lock.json и versions.json.
3. Выполнить npm run build, затем npm test. Проверить затронутый интерфейс.
4. Проверить git diff и список подготовленных файлов. Не добавлять настройки пользователя, деревья, вложения, токены и node_modules.
5. Создать коммит. Если пользователь попросил пуш — отправить main в origin без force.
6. Если пользователь попросил выпуск или установку через релиз — создать тег, точно совпадающий с версией manifest.json, без префикса v. Отправить тег.
7. Создать GitHub Release с заголовком-версией и отдельными вложениями main.js, manifest.json, styles.css, EMOJI-LICENSE.txt. Для многострочного описания использовать файл и gh release create --notes-file.
8. Проверить опубликованный тег, версию manifest.json и SHA-256 скачанных файлов релиза. BRAT получает обновления из релизов, не из обычных коммитов.

GitHub CLI используется для авторизации и релизов. Проверка входа: gh auth status. Не выводить токены.

Локальная установленная копия в хранилище не заменяет исходники. Перед заменой её файлов сохранить резервную копию; никогда не перезаписывать data.json готовым шаблоном.
