# Branch Tree — 0.3.3

Палитра **Loop Hero** исправлена: все 16 HEX-кодов точно перенесены с пользовательского изображения, включая чёрный и белый, в порядке слева направо и сверху вниз. Предыдущий ошибочный встроенный набор автоматически заменяется при загрузке настроек; изменённые пользователем наборы сохраняются. Уже назначенные узлам цвета не перекрашиваются. Доступны наборы **Техника**, **Программирование**, **Спорт**, **Математика** — по 12 иконок.

Кнопки действий расположены на контуре узла и реагируют на наведение/нажатие. При добавлении пункта существующие узлы и соединения плавно перестраиваются. Камера сохраняет положение, пока новый пункт виден, и мягко сдвигается лишь на необходимое расстояние у края поля. Ручное управление прерывает автосдвиг. Выбор цвета анимирует обводки, иконки, подписи и линии без пересоздания дерева. При системном уменьшении анимаций переходы отключены.

Меню цвета пункта показывает текущую палитру над произвольным цветом; здесь же находится «Наследовать цвет родителя». Формы выбираются визуально в панели пункта и общих настройках: круг, пятиугольник, шестиугольник, скруглённый квадрат, мягкая звезда, волнистая печать, шестилучевая звезда, подушка, четырёхлучевая звезда. Новые узлы и соединения плавно появляются (с учётом системного уменьшения анимаций). При наведении активный узел и его кнопки поднимаются над соседями, пустые области не перехватывают курсор.

Исправлена обрезка страницы настроек: в настройках Obsidian используется штатная прокрутка страницы, собственная ограниченная область прокрутки остаётся только в отдельном окне настроек дерева.

Палитры и наборы иконок выбираются карточками. Встроенные палитры содержат 16 цветов, добавлен Catppuccin Mocha (14 акцентов и два светлых текстовых оттенка из https://github.com/catppuccin/palette). Свои палитры создаются в разделе «Создать свою палитру» через цветовые поля; наборы иконок — через поиск Lucide в «Создать свой набор иконок». После «Сохранить и включить» каждый новый пункт получает случайную иконку из набора. Карточка «Вопрос» возвращает вопросики. Горизонтальный промежуток допускает 0 px. Плюсик создаёт потомка одним нажатием даже во время ввода имени.

Настройки открываются шестерёнкой над деревом или через «Настройки → Branch Tree». Размер узла, промежутки по горизонтали/вертикали, масштаб корня и форма обновляют открытые деревья. Палитры («Яркая», «Пастель», «Лес», «Неон») и наборы иконок («Вопрос», «Шахматы», «Идеи») применяются только к новым пунктам. Можно сохранить собственные именованные палитры и наборы, выбрав иконки из поиска. Общие настройки хранятся в `data.json` плагина.

Формы: круг, шестиугольник, скруглённый квадрат, мягкая звезда. В меню «Ещё» пункта можно выбрать индивидуальную форму или вернуть форму из настроек; там же находится «Наследовать цвет родителя».

Встроенная заметка теперь использует одно поле с живым оформлением Markdown. Кнопка `<>` переключает исходный текст в том же поле, сохраняя содержимое и историю редактора. Таблицы, отдельные изображения, вставки `![[...]]` и блоки кода отображаются через MarkdownRenderer; нажатие показывает разметку для редактирования. Элементы управления и связь с файлом отделены от области заметки. При перетаскивании узлов соединения следуют за ними.

Обновление: крупные кружки, более плотная сетка, подписи на цветных плашках. Ширина панели заметки изменяется перетаскиванием её левой границы и сохраняется в документе. Двойной щелчок по границе возвращает ширину 420 px; стрелки влево/вправо при фокусе на границе меняют ширину с шагом 20 px.

Первый прототип дерева заметок для Obsidian. Документ `.skilltree` хранит дерево в JSON; встроенные Markdown-заметки находятся внутри документа. Раскладка пока прямоугольная, вверх и вниз.

## Установка и запуск

1. Скопировать `main.js`, `manifest.json`, `styles.css` в `<хранилище>/.obsidian/plugins/branch-tree/`.
2. В Obsidian открыть «Настройки → Сторонние плагины» и включить **Branch Tree**. Если список не обновился, перезапустить Obsidian.
3. В палитре команд (`Ctrl+P`) выбрать **Branch Tree: Создать дерево заметок**, либо нажать значок ветвления на левой ленте.

## Управление

- Навести курсор на кружок: справа добавить потомка, сверху свернуть/раскрыть, слева удалить ветку с подтверждением.
- Новый пункт сразу получает фокус для ввода имени. `Enter` завершает ввод; `Escape` отменяет переименование.
- Нажатие на название — переименование. Нажатие на кружок — заметка и настройки справа.
- Перетаскивание кружка перемещает поддерево. Наведение на другой пункт увеличивает его; отпускание присоединяет ветку к нему. Без целевого пункта меняется порядок среди соседей; ветки первого поколения можно переносить вверх/вниз.
- Перетаскивание пустого поля — панорамирование, колесо — масштаб относительно курсора. На панели есть «Показать всё дерево» и «К центру».
- `Ctrl+Z` / `Ctrl+Shift+Z` или кнопки панели — отмена / повтор. В поле текста работают обычные текстовые сочетания клавиш. История дерева доступна до закрытия вкладки, максимум 80 действий.
- Цвет вручную переопределяется для пункта; потомки наследуют ближайший заданный цвет. Меню «Ещё → Наследовать цвет родителя» возвращает наследование.
- Связанные Markdown-файлы отображаются в панели и редактируются в отдельной вкладке Obsidian. Встроенный текст сохраняется при привязке и возвращается после её снятия.
- Удаление ветки не удаляет связанные файлы или изображения.

## Сохранение

Используется стандартное автосохранение Obsidian TextFileView (после паузы около двух секунд и при закрытии файла). Сохраняются узлы, связи, текст, цвета, иконки, свёрнутые ветки и положение камеры. Файл с неизвестной версией или повреждённой структурой показывается как ошибка и не заменяется пустым деревом.

## Ограничения прототипа

- Проверяется настольная версия. Круговая раскладка — следующий этап.
- Ссылки на заметки и изображения — пути внутри хранилища. Переименования отслеживаются для открытых деревьев; для закрытых документов автоматического обновления пока нет.
- Встроенные заметки пока не индексируются глобальным поиском, backlinks и графом Obsidian.
- Встроенное поле — самостоятельный CodeMirror-редактор с живым оформлением Markdown, а не полный редактор Obsidian: расширения сторонних плагинов, встроенное автодополнение wikilinks и все особенности Live Preview Obsidian пока не подключены. Связанные файлы редактируются в обычной вкладке Obsidian.
- Содержимое связанной заметки обновляется при повторном открытии панели.
- Одновременное редактирование одного дерева в нескольких окнах и конфликты синхронизации не поддерживаются специально; для теста используйте одну вкладку документа.
- Подписи ограничены двумя строками на поле. Полное название доступно в панели пункта.

## Разработка

Node.js 22+; `npm ci`, `npm run build`, `npm test`. Сначала выполняйте сборку: UI-тесты используют готовый `main.js`. CodeMirror включён в сборку; для установки по-прежнему достаточно трёх файлов плагина.

- `src/model.ts` — формат, валидация, операции над деревом, независимый расчёт расположения.
- `src/main.ts` — интеграция с Obsidian и интерфейс.
- `styles.css` — визуальное оформление.
- `tests/` — проверки модели и интерфейса с эмуляцией DOM и API Obsidian.

API: https://github.com/obsidianmd/obsidian-api
