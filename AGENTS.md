# UI standards
- Use Obsidian theme variables, native setting rows, quiet icon controls and tree/list rows.
- Search results must look like a navigable list, never raised action buttons.
- Do not reduce the note editor's available height or user-selected width to accommodate added tools.
- Put advanced insertion tools in an expandable area below the note header. Never cover the graph with a modal for insertion.
- Keep all node icon sources in one tabbed picker.
- Active toggles need an explicit visible state and aria-pressed.
- Camera movement must not rebuild graph or minimap geometry. Only update transforms and the viewport rectangle.
- Test large graphs and narrow windows before release. Preserve user documents and settings; back up installed artifacts before replacing them.
