# Branch Tree / Skilltree

Вайбкодерский плагин на обсу чтобы строить деревья.

Деревья заметок в отдельных `.skilltree` файлах: встроенный Markdown, ссылки на заметки и другие деревья, изображения, эмоджи и Lucide-иконки, цвета и формы узлов.

Текущая версия: **0.7.21**. Плагин предназначен для настольного Obsidian.

## Установка через BRAT

1. В Obsidian откройте **Настройки → Сторонние плагины → Обзор**.
2. Установите и включите **BRAT**.
3. В настройках BRAT выберите **Add Beta plugin** и вставьте `https://github.com/wermusmoose/skilltree_plugin`.
4. Выберите **Latest**, чтобы получать новые выпуски.
5. Включите **Branch Tree** в списке сторонних плагинов, если он не включился автоматически.

Если Branch Tree уже установлен вручную, добавьте этот же репозиторий в BRAT для отслеживания обновлений. Не удаляйте папку плагина: в `data.json` находятся ваши настройки.

## Ручная установка

В [последнем релизе](https://github.com/wermusmoose/skilltree_plugin/releases/latest) скачайте `main.js`, `manifest.json` и `styles.css`. Поместите их в `<хранилище>/.obsidian/plugins/branch-tree/`, затем включите плагин в Obsidian. При обновлении заменяйте только эти три файла, сохраняя `data.json`.

## Возможности

- Прямоугольная и круговая раскладка дерева, перемещение веток и смена родителя.
- Встроенные заметки, ссылки, вставка изображений из буфера обмена, просмотр изображения по пробелу при наведении.
- Задачи, важные узлы, комментарии; автоматическая метка вопроса для названий с `?`.
- Поиск по названию и встроенному тексту, совместимые фильтры свойств.
- Палитры, формы, наборы иконок и эмоджи; собственные настройки каждого дерева.
- Копирование веток, отмена и повтор, миникарта, экспорт PNG/PDF и ZIP с зависимостями.
- Перестановка кнопок в левой и правой группах инструментов.

## Разработка

Нужен Node.js 22 или новее.

```sh
npm ci
npm run build
npm test
```

Исходники находятся в `src/`, тесты — в `tests/`. Сборка создаёт `main.js`. Установочные файлы публикуются во вложениях GitHub Releases, исходники сохраняются в Git.

Инструкция по выпуску: [RELEASING.md](RELEASING.md). Исторические заметки: [HISTORY.md](HISTORY.md).

## Хранение данных

Деревья и встроенный текст находятся в `.skilltree` файлах внутри хранилища. Вставленные изображения сохраняются в `.skilltree_files`; эту папку тоже нужно переносить и синхронизировать. Связанные заметки остаются обычными файлами хранилища.

Встроенные заметки не входят в глобальный поиск и backlinks Obsidian. История отмены действует в текущем сеансе. Перед массовыми изменениями полезно иметь резервную копию хранилища.
